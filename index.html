Back up

published today, hopefully for good this time

I don't know exactly when the old site went quiet, only that it had been for a while. Getting it back up wasn't the interesting part. The interesting part was deciding what it should actually be once it was.

For a long time this space existed to prove something: that I could stand up a database, wire a form to it, and ship a page that talked back. That proof served its purpose. It doesn't need defending anymore, so I let it go.

What's left is smaller and, I think, more honest. A place to write things down. Nothing behind it but files and a little bit of JavaScript that most people will never notice is there at all.
